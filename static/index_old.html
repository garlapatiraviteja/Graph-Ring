GhostRing

A small seller gets a ranked list of suspicious payments, each backed by proof from their own past fraud, and can send the refund through the PayPal API in one click.

Try it (about a minute)
  1. Find a row tagged PayPal sandbox payment linked and press Explain & decide.
  2. Read the evidence (closest confirmed frauds), the explanation, and the decision. If the decision is refund, press Refund via PayPal sandbox and confirm.
  3. The row then shows refunded. PayPal allows one refund per captured payment.

Rows without a linked payment show the recommendation only. All money is PayPal sandbox test money.
